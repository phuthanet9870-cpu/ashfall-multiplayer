1) อัปเดตเซิร์ฟเวอร์
- แตก Ashfall_Cloudflare_MMO_Server_V3.zip บนเครื่อง
- เปิด github.com/phuthanet9870-cpu/ashfall-multiplayer > Add file > Upload files
- อัปโหลด package.json, wrangler.jsonc และโฟลเดอร์ src ที่มี index.js, service.js, economy.js, skills.js
- กด Commit changes (ไฟล์เดิมให้ยืนยันการแทนที่)
- Cloudflare > Workers & Pages > ashfall-multiplayer > Deployments ตรวจว่า Deployment ล่าสุดขึ้น Ready
- ทดสอบ /health ที่ https://ashfall-multiplayer.phuthanet9870.workers.dev/health
  ต้องมีข้อความ multiplayer ลงท้าย beta-v3
- ตั้ง Secret GM_SPAWN_KEY ภายใน Cloudflare (ยาวอย่างน้อย 16 ตัว) ถ้ายังไม่มี
  อย่าใส่รหัส GM นี้ในเกม ใน GitHub หรือในไฟล์ ZIP

2) อัปเดตตัวเกม
- itch.io > Edit game > Uploads > ลบ ZIP เวอร์ชันก่อนหน้า > Upload files
- เลือก Ashfall_Online_MMO_Beta_V3_Itch.zip
- Kind of project = HTML, This file will be played in the browser
- Save page แล้วทดสอบจากสองเครื่อง / สองเบราว์เซอร์ / สองบัญชี

3) ระบบออนไลน์ที่ทดสอบตรรกะจำลองผ่าน
- GM ออนไลน์ส่งประกาศและคำสั่งเปิด/ปิด PvP กิลวอร์ ตลาด เทรด บอส การทิ้งของไปยังแมพที่ออนไลน์
- GM เสกบอสให้แมพที่มีผู้เล่นทุกแมพ / ซิงก์ HP และคำสั่งลบบอส GM
- ตลาดประมูล: ตั้งขาย-กันไอเทม-ประมูล-คืนเงินผู้ประมูลก่อนหน้า-ซื้อทันที-ถอนประกาศ (ถ้ายังไม่มีคนประมูล)
- หมดอายุรายการ 24 ชั่วโมง: Durable Object alarm คืนของหรือมอบของให้ผู้ชนะพร้อมโอนเงิน
- เทรดสองฝ่าย: ผู้ส่งเสนอไอเทม/เครดิตและขอของตอบแทน ผู้รับกดรับ แล้วเซิร์ฟเวอร์ตรวจยอดและย้ายทรัพย์สินพร้อมกัน
- ทิ้งไอเทมออนไลน์ลงพื้นแมพ ผู้เล่นอื่นเห็นและเข้ามาเก็บได้ โดย ledger กลางตัด/เพิ่มยอดแบบอะตอมมิก
- สร้าง/เข้ากิลด์ออนไลน์, PvP ทีม 3v3 5v5 15v15, กิลวอร์ชิงธง (เฉพาะโหมดทดลองที่มีอยู่จาก V2)
- อนิเมชันเดิน/ใช้สกิลที่ส่งผ่าน WebSocket จาก V2
- บัญชีคลาวด์และเซฟข้ามอุปกรณ์ (สำรอง/โหลดเอง, ตรวจ revision ป้องกันเซฟทับแบบเงียบ)
- อุปกรณ์ออนไลน์บางชนิดมีผลกับสูตรดาเมจ PvP ทดลอง

4) ข้อจำกัดสำคัญก่อนเปิดให้คนทั่วไปเล่นจริง
- ระบบออนไลน์ไม่ใช่การย้ายระบบ MMORPG เดิมทุกส่วนไปคำนวณบนเซิร์ฟเวอร์
- ทอง/ไอเทมในกระเป๋าเดิมยังเป็นของฝั่งเครื่องผู้เล่นและ GM แก้ได้ จึงยังไม่ได้ย้ายเข้าสู่ตลาดออนไลน์หรือการเทรด
- ไอเทมตลาด/ทิ้งของเป็นหมวด “ไอเทมออนไลน์” ที่ได้จากมอนสเตอร์ร่วม / บอส / PvP เท่านั้น
- บอสดั้งเดิมทุกตัว, ดันเจี้ยนทุกชั้น, กิลด์/กิลวอร์แบบเดิมและคอมโบ PvP ทุกเอฟเฟกต์ยังไม่ใช่ระบบ authoritative เต็มรูปแบบ
- เกมยังไม่มีระบบตรวจสอบการเคลื่อนที่ สถิติ พลังโจมตี และการป้องกันโกงสมบูรณ์
- สูตรสกิลที่เซิร์ฟเวอร์คิดดาเมจเป็นสูตร PvP ทดลอง ไม่ได้ใช้บัฟ รูน และแปลงสถานะครบทุกอย่าง
- Cloudflare Worker, บราวเซอร์ และการเล่นพร้อมกันจริงต้องทดสอบหลัง Deploy; สภาพแวดล้อมสร้างไฟล์ไม่สามารถเปิดหน้า Chromium ได้
- แนะนำให้ทดสอบกับบัญชีทดลองก่อน ห้ามใช้เป็นตลาดที่ผูกเงินจริงจนกว่าจะย้ายกระเป๋าเกมเดิมและทำการทดสอบความปลอดภัย

5) วิธีทดสอบเร็ว
- ล็อกอินบัญชีออนไลน์ 2 บัญชี (ไม่ใช้บัญชีเดียวกัน) บน 2 เครื่อง
- เลือกเซิร์ฟเวอร์ + แมพเดียวกัน เห็นผู้เล่นอีกฝ่ายและร่ายสกิล
- เครื่อง A ฆ่ามอนสเตอร์ร่วมจนได้ไอเทมออนไลน์ แล้วไปหน้า Cloud > ทิ้งของ
- เครื่อง B เห็นป้ายของบนพื้น เดินเข้าใกล้แล้วกดเก็บ -> ยอดไอเทมเพิ่มบน B ไม่เพิ่มบน A
- เครื่อง B ประกาศขายไอเทม -> A ซื้อทันที และ B ได้เครดิตหลังหักค่าธรรมเนียม 5%
- ส่งข้อเสนอเทรดที่ระบุของตอบแทน แล้วผู้รับกดยืนยัน
- GM ยืนยัน GM_SPAWN_KEY > ประกาศทั่วเซิร์ฟเวอร์ แล้วเสกบอสทุกแมพ
- ทดสอบ PvP 3v3 ต้องมีผู้เล่นจริง 6 คนบนแมพเดียวกัน ไม่มีบอทเติม
