ASHFALL ONLINE Shared PvE & Original Item Ledger V4 (รุ่นทดสอบ)

ขั้นตอนติดตั้ง
1) แตกไฟล์ ZIP เซิร์ฟเวอร์ ให้ GitHub มี src/index.js src/service.js src/economy.js src/skills.js src/pve.js src/catalog.js src/legacy_generator.js + package.json + wrangler.jsonc อยู่ถูกตำแหน่ง
2) เมื่อ Cloudflare Workers Deploy เสร็จ เปิด /health ต้องเห็น online-pve-v4
3) นำ ZIP เกมอีกไฟล์ขึ้น itch.io: Project type HTML, เลือก This file will be played in the browser
4) ล็อกอิน Cloud Account คนละบัญชีในสองหน้าต่าง แล้วเข้าเซิร์ฟเวอร์/แมพ/ดันเจี้ยนชั้นเดียวกัน
5) เมื่อล่ามอนสเตอร์ออนไลน์ได้ จะมีทองออนไลน์ + ไอเทมในกระเป๋าออนไลน์บนเซิร์ฟเวอร์ คลิกหน้า Cloud เพื่อดูรางวัลไอเทมดั้งเดิม (รหัส UUID) และเสนอขาย/ส่งให้บัญชีอื่น

สิ่งที่ทำใหม่
- Server PvE: 20 แมพฟาร์ม, 4 ดันเจี้ยนและชั้น 1-1000 (ห้องเดียวกันสำหรับชื่อดันเจี้ยน+ชั้นเดียวกัน), ใช้ catalog ที่สกัดจาก game/js/data.js เดิม
- HP/ตำแหน่ง/การเกิดใหม่ของมอนสเตอร์ออนไลน์เป็นของเซิร์ฟเวอร์ และผู้เล่นที่เข้าทีหลังเห็นสถานะเดิม
- ดรอปไอเทมจาก server: 10 หมวดเดิม gear, acc, rune, relic, gem, fashion, stone, cons, srune, cur และโบนัสออนไลน์ โดยใช้ตัวสร้างไอเทมเดิมที่รันฝั่ง Worker
- Server-side ledger สำหรับไอเทมที่ดรอปออนไลน์, โอน/ขายให้ผู้เล่นอีกบัญชีแบบ escrow ใช้ยอดทองออนไลน์, ป้องกันการรับรายการซ้ำและรางวัลซ้ำด้วย receipt

ข้อจำกัดสำคัญ
- ไอเทมและทองที่อยู่ในเซฟเครื่องเดิม รวมถึงที่สร้างด้วย GM ยังไม่ได้ย้ายเข้าบัญชีเซิร์ฟเวอร์แบบเชื่อถือได้
- ไอเทมรุ่นใหม่ที่เก็บบน Worker ยังไม่เชื่อมการใส่/ตีบวก/คราฟต์จากเมนูเดิม และยังไม่ได้รวมตลาดประมูลไอเทม unique เดิมเข้ากับตลาดสินค้าแบบจำนวน
- สมดุล PvE/AI/สกิล/เควสต์/ดันเจี้ยนไม่ใช่ authoritative ทุกตัว ไม่ได้ทดสอบเล่น 2 เครื่องผ่าน itch.io จริง
- อย่าใช้กับระบบซื้อขายเงินจริงหรือเปิดแบบแข่งขันจนกว่าการตรวจสิทธิ์และการป้องกันการโกงจะครบ

หากเปิด Worker ของรุ่นก่อน V4 จะไม่รองรับต้นทางข้อมูลมอนสเตอร์/ไอเทม และปุ่มระบบใหม่จะทำงานผิดพลาด กรุณาติดตั้งทั้งเกมและ Worker รุ่นเดียวกัน
